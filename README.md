# Maker — оболочка сервиса для маркетологов

Кликабельный прототип [Maker](https://trymaker.ru): кабинет маркетолога, который ведёт клиентов.
Стратегия → контент-план → посты, карусели, сторис, клипы, баннеры. Всё в стиле и голосе каждого клиента.

Прототип без бэкенда. Это оболочка, которую дальше «натягивают» на реальный движок.

## Как смотреть кабинет

- **Демо-режим** — плашка «прототип · демо-режим» в правом нижнем углу. Там:
  - сценарии данных: Новый пользователь · Первые шаги · Активный · Деньги кончились;
  - системные состояния: Загрузка · Ошибка · Нет сети;
  - роль «Клиент по ссылке»;
  - «Карта состояний» — каждый экран в каждом состоянии одной кнопкой.
- **Вход** (аватар → «Выйти из кабинета»): код всегда `1234`, можно войти как новый пользователь или как пользователь с готовым кабинетом.
- **Демо-данные** — на 14 октября 2026.
- **Адрес** запоминает место: `prototype.html#/plan/t4`. Такую ссылку можно дать разработчику.

## Для разработки

- **[CLAUDE.md](CLAUDE.md)** — правила интерфейса. Компоненты, плашки, выпадашки, состояния, модель «пользователь → клиенты», выгрузка файлов. Новый экран собирается только из этих компонентов.
- **Кнопки под движок.** Где файл отдаст только движок (ролики MP4, закрывающие документы), стоит обычная кнопка с меткой `data-engine` (`clip-mp4`, `video-mp4`, `billing-doc`). Найдите их поиском по `data-engine`.
- **Выгрузка, которая уже работает в прототипе:**
  - PNG баннеров, слайдов и сторис;
  - Word — стратегия и контент-план;
  - PowerPoint и PDF — презентации;
  - CSV — журнал, расходы, отчёт;
  - ZIP-архивы.
- **[CHANGELOG.md](CHANGELOG.md)** — журнал изменений лендинга.

## Структура

```
landing.html         лендинг (на него ведёт index.html)
prototype.html       кабинет — один файл: разметка, стили, логика
prototype-v1.html    снимок кабинета до перестройки 1 окт 2026
vision.html          видение оболочки
font-specimen.html   подбор шрифтов
img/                 фото и иллюстрации (intro/ — кадры заставки, shots/ — кадры клиентов)
export/              скриншоты проверок вёрстки
CLAUDE.md            правила UI
```

## Запуск локально

Можно просто открыть `landing.html` или `prototype.html` в браузере. Для выгрузки файлов лучше поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.
