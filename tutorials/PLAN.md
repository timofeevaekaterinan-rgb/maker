# Видео Maker — план и прогресс

Задача (Катя, 12 окт 2026): обучающее видео на каждый пункт меню + общий ролик-презентация продукта.
Решения: голос — **нейроголос «Светлана» (Microsoft `ru-RU-SvetlanaNeural` через edge-tts, бесплатно; `.venv`)** + субтитры (Милену Катя забраковала: «машинная»); форматы — **оба**: 16:9 (1920×1080) и 9:16 (1080×1920); разбивка — **по каждому пункту меню**.
Если сессия прервётся (лимиты, сон ноутбука) — продолжать по этому файлу с первого невыполненного пункта. Ничего платного не запускать.

## Как устроено

1. `steps.js` — сценарии роликов: для каждого шага — что сказать, что сделать в прототипе, куда указать курсором.
2. `capture.js` — Chrome (puppeteer-core) открывает прототип, проходит шаги и снимает экран: 16:9 — окно 1600×900 ×1,2; 9:16 — 360×640 ×3. Координаты цели сохраняет в `build/<id>/<fmt>/meta.json`.
3. `voice.js` — озвучка шагов Светланой (edge-tts, повторы при 403, тишина по краям срезается) → `build/<id>/voice/NN.wav` и длительности.
4. `player.html` — сцена `render(t)`: снимок экрана, плавный наезд к цели, курсор и клик, подсветка, субтитры, заставка и финал.
5. `render.js` — покадровая запись сцены (25 к/с) → ffmpeg: кадры + голос + тихая музыка → `out/<id>-16x9.mp4`, `out/<id>-9x16.mp4`.

Сервер прототипа — `maker` на :8934 (`.claude/launch.json`).
