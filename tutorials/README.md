# Обучающие ролики Maker

21 ролик: общий ролик-презентация и по одному на каждый пункт меню. Каждый в двух форматах: 16:9 (1920×1080) и 9:16 (1080×1920). Голос — нейроголос «Светлана», субтитры вшиты.

Видео в git не лежат, они тяжёлые (~540 МБ). Готовые mp4 хранятся на **Яндекс Диске**, в папке «Maker — обучающие ролики». Локально — `out/`, а `upload/` — та же папка с русскими именами для загрузки на диск.

## Как устроено

1. **`steps.js`** — сценарии. У каждого шага: что говорит диктор (`say`), что сделать в прототипе (`do`), на какой элемент указать курсором и подсветкой (`t`), показать ли клик (`click`).
2. **`voice.js <id>`** — озвучка через edge-tts (голос `ru-RU-SvetlanaNeural`). Пишет `build/<id>/voice/`. Уже озвученные фразы не трогает, поэтому после сбоя сервиса (бывает 403) просто запустите ещё раз.
3. **`capture.js <id> [16x9|9x16|all]`** — Chrome открывает прототип, проходит шаги и снимает экран. Координаты цели сохраняет в `build/<id>/<формат>/meta.json`.
4. **`player.html`** — сцена ролика: заставка и финал, наезд камеры, курсор и клик, подсветка, субтитры.
5. **`make.js <id> [формат]`** — покадрово снимает сцену, сводит голос и тихую музыку (`../promo/music_ui_soft.wav`). Результат — `out/<id>-<формат>.mp4`.
6. **`batch.sh <id…>`** — пачка по очереди. На время работы поднимает свой сервер прототипа на `:8935` и не даёт ноутбуку уснуть. Между роликами пауза 90 с, чтобы ноутбук не перегревался.
7. **`dump.js <вид…>`** — подсказка для новых сценариев: какие блоки, кнопки и заголовки есть на экране.

## Пересобрать

Нужны Node, ffmpeg и Google Chrome, плюс один раз:

```bash
npm install && python3 -m venv .venv && ./.venv/bin/pip install edge-tts
```

Один ролик или несколько:

```bash
nohup nice -n 19 ./batch.sh strat plan > build/batch.log 2>&1 &
```

Все ролики:

```bash
nohup nice -n 19 npm run all > build/batch.log 2>&1 &
```

Озвучка и съёмка пропускаются, если уже есть. Поменяли текст `say` — переозвучится только эта фраза. Поменялся интерфейс — удалите `build/<id>/16x9` и `build/<id>/9x16`, и экраны снимутся заново. Ход сборки — в `build/batch.log`.

## Решения

- Голос: Милена из macOS звучит машинно. Выбрали «Светлану»: бесплатно, но текст озвучки уходит в сервис Microsoft. Это только закадровый текст.
- В кадре нет тостов, демо-плашки и подсказок интерфейса. Крупные блоки прокручиваются так, чтобы был виден их верх.
- Новый раздел меню — новый ролик в `steps.js` и строка в таблице выше.
