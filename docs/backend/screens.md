# Карта экранов

Адрес: `#/вид/id?p=клиент` (`routeHash`, `routeParse`, `routeApply`), копия в `localStorage mk-route`. Обновление страницы возвращает на место; карточки, созданные в сессии, после обновления в прототипе не живут (нет бэкенда) — с бэкендом должны. Иерархия для крошек — `NAVH`, `CRUMB`; группы меню — `CR_GRP`.

## Меню (с 9 окт)

```
Главная · Чаты · Входящие (счётчик)
Создать:   Фото и видео · Посты, сторис, клипы · Баннеры · Сайты и страницы · Презентации · Шаблоны
Запустить: Стратегия · Контент-план · Рекламные кампании
Результаты: Публикации и ЦА · Реклама · Финансы и клиенты
Бренд клиента: Стиль · Голос · База фактов · Аудитории
Профиль (аватар): Профиль и доступы · Оплата и документы · Выйти
```
Сверху сайдбара — переключатель клиента («Клиент · Вита», «ждёт ответа: N», «Все клиенты», «+ Новый клиент»). В шапке: крошки, «Чат», «?» справка, колокольчик. Колонка чата — между меню и экраном.

## Состояния

### Сценарии данных (`STATE`, демо-переключатель — в проде определяются данными)
| Код | Что | Признак в данных |
|---|---|---|
| `new` | Новый пользователь: 0 клиентов, баланс = бонус 500 ₽. Разделы — «Сначала заведите клиента»; Главная — «Первые шаги»; стартовый набор доступен | нет клиентов |
| `first` | Первые шаги: 1 клиент, ничего больше; «Первые шаги» держатся, пока не пройдены все 4 (клиент → стратегия → план → первый пост) | `onboardNeeded()` |
| `active` | Рабочий кабинет | — |
| `broke` | Баланс 0: полоса `#bal-bar` на всех экранах «Генерация на паузе — черновики, правки и согласования работают» + «Пополнить»; первое напоминание; платное ведёт в окно пополнения | `balance < 1` |

Стартовый набор и CRM-заглушка «Подключите CRM» — у `new/first` (в прототипе — по сценарию; в проде — по признаку «новый пользователь», критерий — open-questions).

### Пустые экраны — решаются данными, не флагом (`stateEval()`)
- Нет ни одного клиента → в любом разделе (кроме Главной, Оплаты, Профиля, Шаблонов, Финансов) один блок «… появится, когда заведёте клиента» + «Завести клиента».
- Клиент есть, раздел пуст → объяснение, откуда берутся материалы (`NS_TXT`), кнопка создания остаётся. Примеры: «Постов пока нет — посты собираются из тем контент-плана», «Кадров пока нет … Загрузить свои фото», «Результатов пока нет — появятся, когда запустите первую кампанию».
- Внутри экранов: «Стратегии пока нет» + «Расскажите о клиенте»; «Пока тихо» в колокольчике; «Всё отвечено» во входящих; «Ничего не нашли… Сбросить фильтры» в списках; «Сейчас нечего согласовывать» / «Ссылка больше не действует» у клиента; пустой клиент в Голосе/Фактах — «Выберите клиента».
- Блока «Напоминания» нет, если дел нет (не «На сегодня всё»).

### Системные состояния (`SYSST`, на любом экране)
| Код | UI | Требование к бэкенду |
|---|---|---|
| `load` | серые заглушки с переливом вместо контента | быстрые агрегаты; пагинация |
| `err` | «Не получилось загрузить «…»», «черновики и правки не пропали», «Повторить», «Написать в поддержку» | черновики сохраняются на сервере сразу; ошибки с `code` |
| `off` | полоса «Нет соединения», данные видны, генерация приглушена, «правки сохраним и отправим, когда сеть вернётся» | идемпотентные PATCH (очередь офлайн-правок на фронте), `Idempotency-Key` |

### Где что фильтруется по текущему клиенту
Списки всех разделов, Главная (напоминания, недавнее, клиенты), колокольчик (его + общие: баланс, команда, подпись «Только «…» и общие»), «расходы по клиентам», финансы, входящие. Не фильтруются: баланс, лимиты, журнал целиком.
