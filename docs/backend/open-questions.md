# Открытые вопросы

Что в прототипе имитировано или решено условно. Для каждого — где в коде, и кто решает: **П** — продукт, **Б** — бэкенд, **Ю** — юрист.

## Топ-5 (блокируют оценку)

1. **Рекламные кабинеты не подключены (П+Б).** Кампании идут «в ручном режиме»: расход, клики, заявки вносят руками каждый день (`openEntry/enSave`), пауза — вручную в площадке, модерация баннеров — имитация. От этого зависят «Результаты», ROMI, сигналы, отчёты, финансы (реклама в марже). Подключаем API VK Рекламы и Директа сразу или запускаемся на ручном вводе? Где берём erid — интеграция с ОРД или ручная вставка (как сейчас)?
2. **Модель денег (П+Б).** Цена «до N ₽»: холд максимума и списание факта — или списание максимума? Что списываем при ошибке генерации, при отмене, при браке (кадр бесплатно — а ролик, страница)? Округление: цены с долями копейки (3,6925 ₽ за кадр × N). Месячный лимит (`LIMITS.month`) в `spendGate` **не проверяется**. Может ли Редактор тратить баланс, если «оплату не видит»? Списание стартового набора — по шагам или разом?
3. **Провайдеры генерации и 152-ФЗ (П+Б+Ю).** Внутри стоят Seedream, Flux, Kling, Veo; LLM не назван. Доступность и оплата из РФ, передача данных клиентов (тексты, фото, факты) за рубеж, хранение. Какие модели для текста? Нужен ли российский фолбэк?
4. **Ответы на отзывы и сообщения (Б).** У 2ГИС и Яндекс Карт может не быть публичного API для ответов владельца; Telegram-бот не видит личных сообщений пользователей каналу (в демо есть `dm` из Telegram); VK-сообщения требуют токена сообщества с правами на сообщения. Если API нет — оставляем режим «скопировать ответ»?
5. **Идентичность и доступы (П+Б).** Ключи в прототипе — названия (клиент `p:'Вита'`, страница `PAGES.n`, `mix.page`). Нужны: доступ участников по клиентам (сейчас все видят всех), кто видит «Финансы и клиенты», один общий чат кабинета на пользователя или на кабинет (сейчас `CHATS id:'dk'` с переключением клиента), текущий клиент — на сервере или в браузере.

## Демо-данные (на бэкенде заменить реальными расчётами или источниками)

Все цифры прототипа сгенерированы псевдослучайно от фиксированной даты `TODAY = 14 окт 2026`, `T0 = 1 июл 2026`.

| Что | Как получено в прототипе | Чем заменить |
|---|---|---|
| Цифры кампаний (`DAYS`) | генератор `campDay()` из параметров `CAMPS.b` (`sp cpc cr sale chk ctr`), `spike` — искусственный рост цены заявки | ручной ввод / API кабинетов + сверка CRM |
| Журнал списаний (`JOURNAL`) | генератор по `OPS_T` × веса клиентов `PJW`; пополнения подогнаны под баланс | реальный журнал |
| Финансы (`FIN`) | константы: касса 64 000 ₽, зарплаты 5-го и 20-го, аренда 1-го, гонорары клиентов, статусы оплат; производство = расходы журнала × 30 | CRM + ручной ввод |
| Сезонность (`SEASON`) | 12 коэффициентов на клиента вручную | история заявок/оплат; нет истории — не показывать |
| Статистика публикаций (`SST`) | генератор с заданной «лучшей/худшей» рубрикой (`CFG`) | API площадок |
| «Кто реагирует» | доли по хешу названия аудитории | реальные данные площадок по аудиториям (если доступны) или скрыть блок |
| Рейтинги карт (`RATING`) | константы | API карт |
| «N дней без постов» (`SOC_LAST`) | константы | вычислять по дате последней публикации |
| Сигнал «план на следующий месяц» | месяц `'2026-11'` захардкожен | следующий месяц от текущей даты |
| Оплата и документы | октябрь `2026-10-01`, реквизиты, номера счетов | реальные |
| Просмотры колод (`share`) | пусто или демо | события публичной страницы |
| Проверки доменов (`SITES`) | константы | реальные проверки |
| Спорные оплаты (`CRM_DIS`) | три фиксированных записи, засчитываются в кампанию `k1` | результат сверки |
| «Переложить 5 000 ₽» (`rsShift`), поиск группы в CRM (`grFindCRM`) | захардкожены кампании `k1/k2` и клиент «СберТаргет» | общая логика |
| Ответы чата (`chatReply`, `strategyHTML`, `planHTML`, `postsHTML`), темы плана (`PL_BANK`, `PL_IDEA`), тексты постов (`socGen`), баннеры (`VAR_POOL`), ответы во входящих (`ibDraft`), правки поста (`psParse`), разбор рассказа (`ikParse`), разбор кампании (`parseAsk`) | шаблоны и регулярки | LLM-оркестратор (chat-and-agents.md) |
| Картинки при генерации | выбор из `img/` по ключевым словам (`shotPick`, пул в `ipGen`) | генератор изображений |
| Сеансы, команда, профиль (`PF`) | константы | реальные |
| Вход | код всегда `1234`, пароль демо | реальные коды |
| Уведомления (`ntfSeed`) | фиксированный набор | события |
